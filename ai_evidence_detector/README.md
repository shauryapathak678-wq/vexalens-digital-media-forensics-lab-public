# AI Evidence Detector

Forensic AI Image & Screenshot Origin Detector powered by **Abacus AI Smaug** (`abacusai/Smaug-AI-Image-Detector`), **EasyOCR**, and automated category heuristic classification for VexaLens.

## Features
- **AI Image Detection**: Evaluates whether payment receipts, chat screenshots, or digital documents were generated by synthetic AI diffusion/GAN models using `abacusai/Smaug-AI-Image-Detector`.
- **Optical Character Recognition (OCR)**: Extracts visible text from receipts, transaction details, and account balances using EasyOCR.
- **Evidence Category Classification**: Automatically classifies screenshots into `Payment / UPI`, `Bank Receipt`, `Digital Invoice`, `Chat Screenshot`, `Social Media`, or `App Interface` based on regex pattern matching and keyword heuristics.

## Installation

```bash
cd ai_evidence_detector
pip install -r requirements.txt
```

> **Note:** First run will download the Smaug model weights (~1–2 GB) from Hugging Face Hub, which are then cached locally.

## Running the FastAPI Server

```bash
uvicorn api:app --host 0.0.0.0 --port 8000 --reload
```

## API Usage

### Analyze Evidence Image:
```bash
curl -X POST "http://localhost:8000/detect" -F "file=@screenshot.jpg"
```

### Response Format:
```json
{
  "is_ai_generated": true,
  "ai_probability": 0.9421,
  "evidence_category": "Payment / UPI",
  "category_confidence": 0.93,
  "extracted_text": "₹50,000 Payment Successful Rohan Sharma UPI Transaction ID...",
  "text_preview": "₹50,000 Payment Successful Rohan Sharma..."
}
```

### Python Standalone CLI:
```python
from detector import detect

result = detect("screenshot.jpg")
print(result)
```
