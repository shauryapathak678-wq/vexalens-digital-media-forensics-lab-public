Image Trace

Find where an image appears online, and check copies against each other. Hashing and comparison run in your browser. After you confirm external-search consent, choosing an image starts the search automatically.

1. Upload the evidence image

Drop an image here, or click to choose (JPG, PNG, WEBP, GIF)

2. Local analysis

Social platforms strip metadata and recompress images, so SHA-256 only matches byte-identical files. The perceptual hashes (aHash, dHash, pHash) survive resizing and recompression, which is why copies are compared with those.

3. Search engines

Manual route: open an engine, then upload the same file there. If the image is already at a public URL, paste it below to get direct search links.

Google Lens (manual) Yandex Images Bing Visual Search TinEye

Automated route: after consent, choosing an image sends only a metadata-stripped JPEG copy (maximum 1024 px on its long side) to Google Cloud Vision Web Detection, Yandex Image Search API, and TinEye when configured. Bing remains a manual option. Their retention and use policies apply; VexaLens keeps the original image only in your browser and does not save it on the server. Deep search tries crops only after a successful full-image search returns no matches and you select the deep-search button.

Scan investigator-supplied public links

Only scan public URLs you are authorized to review. This scan does not use logins, browser cookies, or CAPTCHA workarounds. Add one post or profile URL per line.

Private accounts, stories, and unindexed posts cannot be found by public reverse-search indexes.

4. Check a candidate copy

Found a similar-looking image on a platform? Save it and load it here to measure how close it is to your evidence image.

5. Case record

Download a timestamped record of the hashes, the searches you ran and any comparisons, for your chain-of-custody notes.

"No matches found" only means the image was not found in the indexes that were searched. Private accounts, stories and unindexed posts cannot be searched by any tool, so absence of results does not prove the image is not online.
